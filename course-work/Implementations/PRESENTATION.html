RiskManagementPlatform

Платформа за оценка на риск при транзакции — курсова работа по софтуерен анализ (SQL Server).

База данни · функции · процедури · тригери · примерни данни

Цел на проекта

  • Автоматична оценка на всяка транзакция чрез набор от правила
  • Изчисляване на риск-скор и вземане на решение (действие + ниво)
  • Създаване на аларми и разпределяне към опашки за анализатори
  • Проследяване на жизнения цикъл: Pending → оценка → преглед → решение

Архитектура (накратко)

Данни

11 таблици: Transaction, Rule, Rule_Execution, Risk_score, Alert, Case_Queue и др.

Логика

2 функции, 2 процедури, 2 тригера — целият workflow е в SQL Server.

Исторически прагове

Risk_score с Valid_from / Valid_to — стара (3 нива) и нова (6 нива) конфигурация.

Правила

10 правила с тегла; активност през Rule_Availability.

Поток при оценка

Transaction → usp_EvaluateTransaction → Rule_Execution (активни правила) → fn_GetTransactionScore → fn_GetRiskDecision → UPDATE Transaction.Status → [ниво ≥ 3] Alert + Case_Queue → анализатор променя Alert → trg_Alert_StatusChange → Transaction

Функции

fn_GetTransactionScore

  • Скаларна
  • Сума на Calculated_score при Is_triggered = 1
  • Връща 0, ако няма задействани правила

fn_GetRiskDecision

  • Таблична (inline TVF)
  • Скор + дата → Action и Risk_level
  • Граници: Low ≤ скор ≤ High (включително)
  • Валидност: Valid_from … Valid_to

Съответстват на изискванията и се ползват директно от usp_EvaluateTransaction.
